# Звёздное небо — шаг за шагом

Учебник звёздного неба для подготовки к олимпиаде по астрономии: 53 урока, все 88 созвездий,
по одному созвездию за раз. Каждое новое созвездие ищется от уже знакомых по жёлтым «указателям».
Сайт на двух языках: русском и английском.

- **Уроки** — карта с новым созвездием, как его найти, главные звёзды, объекты, факты для олимпиады, «Проверь себя».
- **Тренировка** — 4 типа вопросов (узнать созвездие по звёздам, показать созвездие, найти звезду, назвать звезду); ошибки повторяются чаще.
- **Задачи** — в стиле олимпиад на знание неба: созвездия на карте без линий, видимость и высота звёзд, Солнце и Луна по датам, звёзды и обозначения, плюс задачи с подробным решением. Ответ проверяется сразу, после ответа — решение. Три уровня сложности: лёгкий (яркие звёзды, известные созвездия, склонения даны), средний, сложный (тусклые созвездия, звёзды 2–3-й величины, близкие варианты, даты у границ созвездий); после пяти верных ответов подряд сайт предлагает уровень выше.
- **Атлас** — всё небо с поиском; щелчок по звезде показывает координаты и видимость на твоей широте.
- **Шпаргалка** — греческий алфавит, ярчайшие звёзды с координатами, даты Солнца в созвездиях, что на юге в полночь по месяцам, созвездия, не заходящие и не видные на твоей широте, формулы, как решать задачи, все 88 созвездий.

**Южное полушарие.** На главной выбирается полушарие, в атласе, шпаргалке и задачах — широта (поле или кнопки городов: Москва … Сидней, Кейптаун, Буэнос-Айрес). В южном полушарии карта поворачивается «юг сверху» (кнопка на карте), в «Тренировке» и «Задачах» спрашивается то, что видно с этой широты, в задачах — южные города и формулы для южного полушария, уроки предупреждают, если созвездие оттуда не видно. У южан свой маршрут уроков: те же 53 урока, но от Южного Креста и Центавра — через Канопус, Орион и Скорпион — к северным созвездиям в конце, со своими указателями и текстами «Как найти». Его тексты (`south.js`, ~20–30 КБ) загружаются только при южной широте — северянам он не стоит ничего.

На телефоне панель с текстом можно свернуть (карта на весь экран) или развернуть (текст на весь экран) — кнопками на её полоске или смахиванием. Телефон боком и планшет получают свою раскладку: карта и текст рядом.

Прогресс сохраняется в браузере (localStorage) и общий для обоих языков.

## Адреса

| Адрес | Что там |
|---|---|
| `/` | выбирает язык (прошлый выбор или язык браузера) и переходит на `/ru/` или `/en/` |
| `/ru/`, `/en/` | главная страница: лёгкая, без карты; пока её читают, карта загружается в фоне |
| `/ru/app/#lesson/UMa` | урок (id урока — из `src/data/lessons.ts`) |
| `/ru/app/#quiz`, `#tasks`, `#atlas`, `#atlas/Ori`, `#ref` | тренировка, задачи, атлас (можно сразу на созвездии), шпаргалка |
| `/ru/lessons/lyr/` | страница урока для поисковиков: текст, картинка с указателями, кнопка «Открыть урок на карте» (id урока строчными, `_` → `-`) |
| `/star-atlas-ru.html`, `/star-atlas-en.html` | всё приложение одним файлом — для телефона без интернета |

Раздел записан после `#`, поэтому ссылки работают на любом статическом хостинге без настройки и в файле
без сервера. Кнопки «назад/вперёд» браузера переходят между уроками и вкладками.

## Как открыть

- **На компьютере:** открыть `public/index.html` двойным щелчком.
- **На телефоне без интернета:** скопировать на телефон `dist/star-atlas-ru.html` (или `-en`) и открыть его в Chrome.
  Его же можно скачать по ссылке с главной страницы сайта.
- **На телефоне по Wi-Fi:** `npm run serve` на компьютере, затем на телефоне открыть `http://<IP-компьютера>:8080`.

Работает во встроенном браузере Android 5–6 (Chrome 37+) и новее: код компилируется в ES5,
без Set/Map, Pointer Events, CSS-переменных и других новых возможностей.

## Тексты и переводы

Все тексты сайта — в таблицах `texts/*.csv`: столбец `key` и по столбцу на язык.

| Таблица | Что внутри |
|---|---|
| `texts/ui.csv` | надписи интерфейса и главной страницы, форматы чисел, широта по умолчанию |
| `texts/catalog.csv` | названия созвездий (и родительный падеж для «α Лиры»), имена звёзд, объекты, греческий алфавит, астеризмы |
| `texts/lessons.csv` | названия блоков и тексты уроков: `lessons.<id>.find`, `.look`, `.facts.1`…, подписи указателей `.labels.1`… |
| `texts/tasks.csv` | задачи: шаблоны генерируемых задач (`tasks.gen.*`), задачи с решением (`tasks.solved.<id>.*`), города, советы «как решать» |

Таблицы открываются в Excel, LibreOffice, Google Таблицах или в VS Code (расширение Rainbow CSV / Edit CSV).
Разделитель — точка с запятой, кодировка — UTF-8. В Excel сохраняй как «CSV UTF-8», иначе сборка
скажет, что файл не в UTF-8.

**Новая задача с решением:** строка в `SOLVED` (`src/data/tasks.ts`: уровень, тип ответа, номер верного варианта или число
с допуском, звёзды и созвездия для карты) и тексты `tasks.solved.<id>.text`, `.options.N`, `.solution` в `texts/tasks.csv`.
Если ответ можно посчитать по каталогу — добавь проверку в `verify` в `tools/check.ts`.

- `{con}`, `{n}` — подстановки: их нужно сохранить в переводе как есть.
- `{n:звезда|звезды|звёзд}` — слово в нужной форме для числа `n` (в английском две формы: `{n:star|stars}`).
- В текстах уроков можно писать HTML: `<b>`, `<i>`, `<sup>m</sup>`.
- Пустая ячейка перевода — при сборке подставится русский текст, а сборка напишет предупреждение.
- **Новый язык:** добавить столбец (например, `de`) во все три таблицы и правило форм множественного
  числа в `PLURAL` (`src/i18n/index.ts`); выбор языка по браузеру — в `public/index.html`.
  Сборка сама сделает `/de/`; кнопка языка в шапке переключает языки по кругу.

`npm run texts` проверяет таблицы: ключи не повторяются, подстановки в переводе те же, что в русском.
`npm test` дополнительно проверяет, что у каждого урока, созвездия, звезды и объекта есть тексты на всех языках.

## Сборка

```
npm install
npm run build   # таблицы → проверка типов → public/app.js, страницы языков, dist/star-atlas-*.html
npm test        # данные уроков, переводы, ответы задач по каталогу, 6000 сгенерированных задач
npm run e2e     # эмуляция старого Chrome Android 5–6: адреса, касания, щипок, Млечный Путь, задачи, панель, телефон боком, главная (нужен Chrome)
npm run perf    # время загрузки и кадра на компьютере и на «слабом телефоне»
npm run images  # картинка-превью для соцсетей и значки сайта (нужен Chrome; результат — в git)
```

Код — TypeScript в `src/`: `tsc` компилирует в ES5 (`lib: es5` не даёт использовать новые API),
`tools/build.js` склеивает его esbuild с проверкой `--target=es5` и собирает страницы.

| Папка / файл | Что внутри |
|---|---|
| `src/main.ts` | запуск: вкладки, адреса |
| `src/core/` | данные неба и геометрия (`sky.ts`, `math.ts`), общие типы |
| `src/map/skymap.ts` | отрисовка карты (canvas, стереографическая проекция) |
| `src/data/` | устройство уроков (созвездия, звёзды, указатели, вид карты), латинские названия, координаты объектов, задачи с решением, факты для задач |
| `src/tabs/` | вкладки: уроки, тренировка, задачи, атлас, шпаргалка |
| `src/tasks/generate.ts` | генераторы задач: ответ считается из данных неба |
| `src/ui/` | состояние и сохранение, адреса (`router.ts`), положение панели (`sheet.ts`), надписи поверх карты, переключатели |
| `src/i18n/` | текущий язык `T`, подстановки `fill()`, форматы чисел и координат |
| `src/pages/lesson.ts` | страницы уроков для поисковиков и список уроков на главной (их собирает `tools/build.js`) |
| `src/app.html`, `src/home.html`, `src/lesson.html` | шаблоны страниц приложения, главной и урока (`{{…}}` — тексты из таблиц) |
| `texts/*.csv` | все тексты на всех языках |
| `public/sky.js` | звёзды, линии и границы созвездий, Млечный Путь (генерируется) |

## Поисковики

Всё, что в адресе после `#`, поисковики отдельными страницами не считают: для них приложение — одна страница.
Поэтому у каждого урока есть ещё обычная страница `/<язык>/lessons/<id>/` — с текстом урока и картинкой
созвездия (SVG по тем же данным, что карта), а на главной — список всех уроков со ссылками на эти страницы.

Сборка делает и остальное: `canonical` и `hreflang` (ru ↔ en) с полными адресами, теги Open Graph (превью ссылки
в мессенджерах), `sitemap.xml`, `robots.txt`, `404.html`, значок сайта файлом. Однофайловые `star-atlas-*.html`
закрыты от индексации (`noindex`) — это копии приложения.

- **Адрес сайта** — `homepage` в `package.json`. После подключения своего домена поменять его там и пересобрать.
- **Картинки** `public/og-<язык>.png` (превью 1200×630), `favicon.ico`, `apple-touch-icon.png` делает `npm run images`
  (нужен Chrome) — после изменения названия, описания сайта или картинки Ковша. Результат хранится в git.
- **Свой домен на GitHub Pages:** Settings → Pages → Custom domain; у регистратора — записи A на 185.199.108.153,
  185.199.109.153, 185.199.110.153, 185.199.111.153 (и CNAME `www` → `<пользователь>.github.io`), затем «Enforce HTTPS».
  `robots.txt` работает только на своём домене: поисковики ищут его в корне сайта.
- **Google Search Console и Яндекс.Вебмастер:** добавить сайт, подтвердить владение (запись TXT в DNS или файл
  в `public/`), отправить `<адрес сайта>/sitemap.xml`.

## Скорость

Главная страница — около 30 КБ без внешних файлов, страница урока — до 35 КБ. Карта рассчитана на слабые телефоны: проекция без
тригонометрии, звёзды рисуются пачками по цвету, Млечный Путь — в 1/3 разрешения, при медленных кадрах
автоматически снижается плотность пикселей. Тексты загружаются только для выбранного языка.
Добавь `?fps` к адресу, чтобы увидеть время отрисовки кадра (`?debug` открывает доступ к приложению из консоли).

## Данные

Звёзды (каталог Hipparcos до 6ᵐ), линии и границы созвездий, Млечный Путь, имена звёзд — из проекта

```
python tools/build_sky.py <папка с json из d3-celestial/data> public/sky.js
```
