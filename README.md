# Звёздное небо — шаг за шагом

Учебник звёздного неба для подготовки к олимпиаде по астрономии: 53 урока, все 88 созвездий,
по одному созвездию за раз. Каждое новое созвездие ищется от уже знакомых по жёлтым «указателям».
Сайт на двух языках: русском и английском.

- **Уроки** — карта с новым созвездием, как его найти, главные звёзды, объекты, факты для олимпиады, «Проверь себя».
- **Тренировка** — 4 типа вопросов (узнать созвездие по звёздам, показать созвездие, найти звезду, назвать звезду); ошибки повторяются чаще.
- **Атлас** — всё небо с поиском; щелчок по звезде показывает координаты и видимость на твоей широте.
- **Шпаргалка** — греческий алфавит, ярчайшие звёзды с координатами, даты Солнца в созвездиях, формулы, все 88 созвездий.

Прогресс сохраняется в браузере (localStorage) и общий для обоих языков.

## Адреса

| Адрес | Что там |
|---|---|
| `/` | выбирает язык (прошлый выбор или язык браузера) и переходит на `/ru/` или `/en/` |
| `/ru/`, `/en/` | главная страница: лёгкая, без карты; пока её читают, карта загружается в фоне |
| `/ru/app/#lesson/UMa` | урок (id урока — из `src/data/lessons.ts`) |
| `/ru/app/#quiz`, `#atlas`, `#atlas/Ori`, `#ref` | тренировка, атлас (можно сразу на созвездии), шпаргалка |
| `/star-atlas-ru.html`, `/star-atlas-en.html` | всё приложение одним файлом — для телефона без интернета |

Раздел записан после `#`, поэтому ссылки работают на любом статическом хостинге без настройки и в файле
без сервера. Кнопки «назад/вперёд» браузера переходят между уроками и вкладками.

## Как открыть

- **На компьютере:** открыть `public/index.html` двойным щелчком.
- **На телефоне без интернета:** скопировать на телефон `dist/star-atlas-ru.html` (или `-en`) и открыть его в Chrome.
  Его же можно скачать по ссылке с главной страницы сайта.
- **На телефоне по Wi-Fi:** `npm run serve` на компьютере, затем на телефоне открыть `http://<IP-компьютера>:8080`.

Работает во встроенном браузере Android 5–6 (Chrome 37+) и новее: код компилируется в ES5,
без Set/Map, Pointer Events, CSS-переменных и других новых возможностей.

## Тексты и переводы

Все тексты сайта — в таблицах `texts/*.csv`: столбец `key` и по столбцу на язык.

| Таблица | Что внутри |
|---|---|
| `texts/ui.csv` | надписи интерфейса и главной страницы, форматы чисел, широта по умолчанию |
| `texts/catalog.csv` | названия созвездий (и родительный падеж для «α Лиры»), имена звёзд, объекты, греческий алфавит, астеризмы |
| `texts/lessons.csv` | названия блоков и тексты уроков: `lessons.<id>.find`, `.look`, `.facts.1`…, подписи указателей `.labels.1`… |

Таблицы открываются в Excel, LibreOffice, Google Таблицах или в VS Code (расширение Rainbow CSV / Edit CSV).
Разделитель — точка с запятой, кодировка — UTF-8. В Excel сохраняй как «CSV UTF-8», иначе сборка
скажет, что файл не в UTF-8.

- `{con}`, `{n}` — подстановки: их нужно сохранить в переводе как есть.
- `{n:звезда|звезды|звёзд}` — слово в нужной форме для числа `n` (в английском две формы: `{n:star|stars}`).
- В текстах уроков можно писать HTML: `<b>`, `<i>`, `<sup>m</sup>`.
- Пустая ячейка перевода — при сборке подставится русский текст, а сборка напишет предупреждение.
- **Новый язык:** добавить столбец (например, `de`) во все три таблицы и правило форм множественного
  числа в `PLURAL` (`src/i18n/index.ts`); выбор языка по браузеру — в `public/index.html`.
  Сборка сама сделает `/de/`; кнопка языка в шапке переключает языки по кругу.

`npm run texts` проверяет таблицы: ключи не повторяются, подстановки в переводе те же, что в русском.
`npm test` дополнительно проверяет, что у каждого урока, созвездия, звезды и объекта есть тексты на всех языках.

## Сборка

```
npm install
npm run build   # таблицы → проверка типов → public/app.js, страницы языков, dist/star-atlas-*.html
npm test        # данные уроков и переводы: звёзды, объекты, указатели, 88 созвездий, все тексты
npm run e2e     # эмуляция старого Chrome Android 5–6: адреса, касания, щипок, Млечный Путь, главная (нужен Chrome)
npm run perf    # время загрузки и кадра на компьютере и на «слабом телефоне»
```

Код — TypeScript в `src/`: `tsc` компилирует в ES5 (`lib: es5` не даёт использовать новые API),
`tools/build.js` склеивает его esbuild с проверкой `--target=es5` и собирает страницы.

| Папка / файл | Что внутри |
|---|---|
| `src/main.ts` | запуск: вкладки, адреса |
| `src/core/` | данные неба и геометрия (`sky.ts`, `math.ts`), общие типы |
| `src/map/skymap.ts` | отрисовка карты (canvas, стереографическая проекция) |
| `src/data/` | устройство уроков (созвездия, звёзды, указатели, вид карты), латинские названия, координаты объектов |
| `src/tabs/` | вкладки: уроки, тренировка, атлас, шпаргалка |
| `src/ui/` | состояние и сохранение, адреса (`router.ts`), надписи поверх карты, переключатели |
| `src/i18n/` | текущий язык `T`, подстановки `fill()`, форматы чисел и координат |
| `src/app.html`, `src/home.html` | шаблоны страниц приложения и главной (`{{…}}` — тексты из таблиц) |
| `texts/*.csv` | все тексты на всех языках |
| `public/sky.js` | звёзды, линии и границы созвездий, Млечный Путь (генерируется) |

## Скорость

Главная страница — около 25 КБ без внешних файлов. Карта рассчитана на слабые телефоны: проекция без
тригонометрии, звёзды рисуются пачками по цвету, Млечный Путь — в 1/3 разрешения, при медленных кадрах
автоматически снижается плотность пикселей. Тексты загружаются только для выбранного языка.
Добавь `?fps` к адресу, чтобы увидеть время отрисовки кадра (`?debug` открывает доступ к приложению из консоли).

## Данные

Звёзды (каталог Hipparcos до 6ᵐ), линии и границы созвездий, Млечный Путь, имена звёзд — из проекта
[d3-celestial](https://github.com/ofrohn/d3-celestial) (Olaf Frohn, BSD-3). Пересборка `public/sky.js`:

```
python tools/build_sky.py <папка с json из d3-celestial/data> public/sky.js
```
