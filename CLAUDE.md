# Звёздное небо — шаг за шагом

Сайт-учебник звёздного неба. Пользователь готовится к олимпиаде по астрономии: учит карту неба, чтобы
узнавать созвездия в задачах (карта без линий, координаты звёзд, видимость на широте), а не для
наблюдений на улице — подход «учи то, что сейчас на небе» отвергнут. Метод — как в детской книжке:
созвездие за созвездием, каждое новое находится от уже знакомых по указателям, начиная с Большого Ковша.
Общение — на русском. Сайт на двух языках (ru, en); русский — основной и эталонный.
Подробности для людей — в README.md.

## Главное ограничение: старый Chrome на Android 5–6

Сайт должен работать и не тормозить во **встроенном, не обновлённом** Chrome 37–50 (Android 5–6) на слабых телефонах.

- Код компилируется в **ES5**: `tsc` с `target: es5` и `lib: ["es5", "dom"]` (не даст использовать Set, Map,
  Promise, Array.find и т. п.), затем esbuild `--target=es5` проверяет синтаксис.
- `lib.dom` пропускает новинки DOM — следить вручную. Нельзя: `Set`/`Map`/`Symbol`/`Promise`,
  `NodeList.forEach` (есть `each()` в `src/ui/dom.ts`), `TypedArray.fill`, `Object.assign/entries/values`,
  `Array.from/find/includes`, `String.includes/startsWith/padStart`, `KeyboardEvent.key` (только `keyCode`),
  Pointer Events без запасного варианта (см. `SkyMap.initEvents`: pointer → иначе touch + mouse),
  `ResizeObserver` без запасного `resize`. То же — во встроенном скрипте `src/home.html`.
- CSS: без переменных `var()`, без `gap` у flex, без grid, без `backdrop-filter`/blur. Палитра — в комментарии
  в начале `public/style.css`.
- Символы — только те, что есть в шрифтах старого Android: не использовать ☉ ◐ ⟲ ⅔ и эмодзи; иконки — inline SVG.

## Команды

- `npm run build` — `tools/texts.js` (таблицы → `src/i18n/gen/ru.json` для типов) → `tsc` → `.build/` →
  `tools/build.js`: `public/app.js`, для каждого языка `public/<язык>/index.html` (главная),
  `public/<язык>/app/index.html` + `text.js` (приложение) + `south.js` (тексты южного маршрута),
  `dist/star-atlas-<язык>.html` (один файл без зависимостей, `south.js` встроен).
- `npm test` — данные уроков и тексты (`tools/check.ts`): все 88 созвездий ровно в одном уроке, звёзды/объекты/указатели
  находятся, южный маршрут (каждый урок ровно раз, блоки подряд, указатель начинается от пройденного созвездия или
  звезды, к которой уже вёл указатель, подписи и «Как найти» на всех языках), у каждого урока/созвездия/звезды/объекта есть тексты на всех языках, число подписей = числу указателей,
  определение созвездия по точке сверяется с каталогом, даты Солнца в созвездиях, списки Млечного Пути — по его карте,
  ответы задач с решением — по каталогу (`verify`), каждый генератор задач — по 300 раз на каждом языке.
- `npm run e2e` — эмуляция старого Chrome (`tools/e2e/old-browser.js [--dist] [--lang=en]`): удаляет новые API,
  открывает урок по адресу `#lesson/Boo`, проходит «Проверь себя» касаниями, проверяет «назад», ссылку на другой язык,
  щипок, заливку Млечного Пути с 400 точек обзора, свернуть/развернуть панель, задачу, снятие выделения в атласе,
  раскладку телефона боком (924×412), южное полушарие (карта «юг сверху», `south.js` не грузится на севере,
  южный маршрут после выбора Сиднея и после перезапуска, возврат на север) и главную; для ru/en, `public` и `dist`.
- `npm run perf` — загрузка главной и карты, время кадра на компьютере и на «телефоне» с процессором ×10 медленнее.
  Бюджет 16 мс, сейчас ~14–15 мс.
- После правок кода: `build` → `test` → `e2e` (и `perf`, если менялась отрисовка); смотреть скриншоты в
  `tools/e2e/shots/`. Нужен установленный Chrome (`CHROME_PATH`, по умолчанию стандартный путь).
- В адресе: `?fps` — время кадра в углу экрана, `?debug` — `window.__app` (map, sky) для тестов.

## Тексты — только в таблицах

- Все тексты (интерфейс, главная, уроки, названия созвездий/звёзд/объектов) — в `texts/ui.csv`, `catalog.csv`,
  `lessons.csv`, `tasks.csv`: столбец `key` + столбец на язык. В коде строк для людей нет — только `T.ui.…` (`src/i18n`).
  Ключ — путь в объекте `Texts` (`src/i18n/types.ts`); число в ключе — номер в списке с 1 (`lessons.UMa.facts.2`).
- Набор надписей `T.ui/page/home` TypeScript берёт из русского столбца (`src/i18n/gen/ru.json`): новую надпись
  сначала добавить в таблицу. Шаблоны: `{con}` — подстановка через `fill()`, `{n:форма|формы|форм}` — множественное число.
- CSV: разделитель `;`, UTF-8 с BOM, CRLF (так их открывает Excel). Парсер принимает и `,`. Пустая ячейка перевода →
  при сборке русский текст и предупреждение; разные `{подстановки}` в переводе — ошибка сборки.
- Подписи указателей урока — `lessons.<id>.labels.N` в порядке `pointers` в `src/data/lessons.ts`.
- Южный маршрут — `texts/south.csv` (блоки `s-*`, `lessons.<id>.find/labels/html`). Если у урока есть строки в
  south.csv, подписи берутся **только** оттуда (в порядке `pointers` шага `SOUTH_ROUTE` или урока); «Как выглядит» и
  факты — общие из lessons.csv.
- В английском созвездия называются по-латыни, обозначения звёзд — с латинским родительным падежом (α Lyrae);
  `cons.<abbr>.meaning` — перевод названия (Great Bear). В русском — «α Лиры», второе название — латинское.
- Факты в английских уроках — перевод русских; «в Москве / средней полосе России» заменено широтой (~56° N).
- Точка летнего солнцестояния с 1990 года — **в Тельце** (0,1° от границы с Близнецами), весеннего равноденствия —
  в Рыбах. В текстах было «в Близнецах» — это ошибка, её поймала проверка задачи `solstice-con`.

## Устройство и то, что легко сломать

- `src/data/lessons.ts` — 53 урока (только устройство: созвездия, звёзды, указатели, вид); `src/data/constellations.ts` —
  латинские названия и родительный падеж (исправлены по IAU: CrA, Cru, Ser); `src/data/dso.ts` — координаты объектов;
  `src/map/skymap.ts` — отрисовка; `src/core/sky.ts` — данные и геометрия; `src/tabs/` — вкладки;
  `src/ui/` — состояние, адреса, надписи поверх карты; `src/main.ts` — запуск.
- Маршрут уроков — `src/ui/course.ts`: `course()` — северный `LESSONS` или южный (`SOUTH_ROUTE` в `lessons.ts`:
  порядок, блок и свои указатели поверх тех же уроков). Южный — только при `state.lat < 0` **и** загруженном
  `window.TEXT_SOUTH`. Номер урока зависит от маршрута, поэтому текущий урок хранится по id (`sa.lessonId`),
  номер (`state.lesson`) пересчитывает `syncLessonIndex()`. Везде, где нужен список уроков по порядку, —
  `course()`/`courseBlocks()`/`blockTitle()`/`lessonText()`, а не `LESSONS`/`BLOCKS`/`T.blocks`/`T.lessons`.
- `south.js` грузится лениво: `app.html` при сохранённой южной широте пишет его `<script>` до остальных (без лишнего
  запроса после запуска); иначе `ensureCourse()` подгружает его при переходе через экватор, `main.ts` после этого
  пересчитывает номер урока и список. Главная делает prefetch `south.js`, когда выбрано южное полушарие.
- Адреса: язык — в пути (`/ru/`, `/en/`), раздел — после `#` (`#lesson/<id>`, `#quiz`, `#atlas[/<abbr>]`, `#ref`),
  `src/ui/router.ts`. Каждый переход — запись в истории; урок записывает адрес сам (`openLesson`, `goLesson`),
  атлас с созвездием — `goCon`; адрес ставится **до** `setTab`, иначе в истории появляется лишний шаг.
  На `file://` к ссылкам вида `../` дописывается `index.html`.
- Прогресс в localStorage (`sa.*`) общий для всех языков: ключи — id уроков, `sa.lessonId` — текущий урок
  (`sa.lesson` — его номер в текущем маршруте; по нему раньше хранился урок).
  `sa.lang` — последний язык (по нему корневая страница выбирает, куда перейти). Широта по умолчанию — из таблицы.
- Проекция стереографическая, **север сверху, восток слева** (как на настоящих картах). Все точки хранятся
  единичными векторами в `Float32Array`, `projV` — без тригонометрии. Звёзды рисуются пачками по цвету,
  Млечный Путь — в отдельный холст 1/3 разрешения.
- **Заливка Млечного Пути** (`drawMilkyWay`, `polygon`, `clampedArc`, `Sky.mwContains`): если точка,
  противоположная центру экрана, лежит внутри области, evenodd-заливка выворачивается — поэтому добавляется
  большой прямоугольник; далёкие вершины прижимаются к окружности за экраном с рекурсивным дроблением по сфере.
  Не упрощать — иначе при прокрутке меняется цвет неба (была такая ошибка).
- `Sky.conAt` (созвездие по точке): сначала отсев по описанному кругу контура, иначе контуры с обратной
  стороны сферы дают ложные попадания.
- `SkyMap.adapt` снижает плотность пикселей, затем число слабых звёзд, если кадр дольше 30 мс; первые 20 кадров
  не учитываются (холодные кэши).
- Имена звёзд в уроках, подписях и тренировке — только отобранные (`catalog.csv` → `stars.*`, `sky.curatedName`);
  малоизвестные каталожные имена показываются только в атласе (из `sky.js`: русское или английское поле).
- Указатели уроков: `{line: [a, b, t]}` — продолжение большого круга от a через b к t; `{path}` и `{poly}`.
  Новый указатель сначала проверить расчётом (смещение от цели, во сколько раз продолжить): тексты уроков
  опираются на эти числа («×5», «столько же»).
- Факты в уроках должны быть точными для олимпиады — сомнительное лучше не писать.
- Задачи (`src/tabs/tasks.ts`, генераторы — `src/tasks/generate.ts`): ответ генерируемых задач считается из каталога,
  спорные случаи (звезда у границы видимости, Солнце/Луна у границы созвездий) генератор отбрасывает. Задачи с решением —
  `SOLVED` в `src/data/tasks.ts` + тексты `tasks.solved.<id>.*`; вычислимые ответы проверяет `verify` в `tools/check.ts`.
  Это задачи в стиле олимпиад, написанные для сайта, — не перепечатка олимпиадных заданий.
  Уровни (`TaskLevel`: easy/mid/hard) меняют параметры генераторов — что именно, описано в начале `generate.ts`;
  «известные» созвездия для лёгкого уровня — `FAMOUS` в `src/data/sky-facts.ts`. У задач с решением уровень задан вручную.
- Раскладка (`public/style.css`): ≥1200 px — три колонки; 900–1199 — список уроков выезжает (☰); ≤899 — карта сверху,
  панель снизу («шторка»); `(orientation: landscape) and (max-height: 520px)` — телефон боком: вкладки в шапке, без
  нижней панели, карта и текст рядом. Положение панели — `src/ui/sheet.ts`, классы `sheet-min`/`sheet-max` на `<body>`;
  после смены — `map.resize()` (в старом Chrome нет ResizeObserver). Текст панели — в `#panel` (`.panel-body`).
- Атлас: повторный щелчок по выделенному созвездию/звезде/объекту, кнопка × или Esc снимают выделение.
- Южное полушарие: всё зависит от `state.lat` (знак — полушарие). Широту меняет `ui/place.ts` (поле + кнопки городов
  в атласе, шпаргалке, задачах) или выбор полушария на главной. Переход через экватор включает `state.southUp` — карта
  «юг сверху» (`SkyMap.opt.southUp`: в `prep()` оси «восток/север» в обратную сторону, в `panBy` — знак). Наборы
  «видимое с моей широты» (тренировка, задачи) — созвездия, центр которых в кульминации выше 10°. Генераторы задач берут
  `Scope {lat, all}`; для южных городов — тексты `*South`. Уроки — по южному маршруту (см. выше), в уроках —
  предупреждение, если созвездие не видно с широты.
- Главная (`src/home.html`) — без внешних файлов, картинку Ковша рисует `tools/build.js` из `sky.js`;
  приложение подгружается на ней через `<link rel="prefetch">`.
- Подключаемые файлы в шаблонах — только с меткой версии: `app.js?v={{vApp}}` (`vStyle`, `vSky`, `vText`, `vSouth`,
  md5 содержимого). GitHub Pages разрешает кэш на 10 минут: без метки браузер берёт старый `app.js` к новой
  странице (так было: вкладки оставались русскими на `/en/`). Для `dist/` метки вырезаются перед встраиванием.

## Данные

`public/sky.js` генерирует `tools/build_sky.py` из данных d3-celestial (BSD-3); Мира (ο Кита) добавлена вручную.
Имена звёзд: `[Байер, созвездие, рус., Флемстид, англ.]`. Исходники скачать в отдельную папку и пересобрать:

```
for f in stars.6.json starnames.json constellations.json constellations.lines.json constellations.bounds.json mw.json; do
  curl -sSL -o "<папка>/$f" "https://raw.githubusercontent.com/ofrohn/d3-celestial/master/data/$f"; done
python tools/build_sky.py <папка> public/sky.js
```
